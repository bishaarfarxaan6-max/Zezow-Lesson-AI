Security Policy

Zezow Lesson AI Security

The security of Zezow Lesson AI and its community is important to us.

Reporting a Vulnerability

If you discover a security vulnerability, please report it privately to the project maintainers.

Please do not publicly share security vulnerabilities before they have been reviewed.

Supported Versions

Security updates will be provided for actively maintained versions of Zezow Lesson AI.

Security Best Practices

- Never share passwords or API keys.
- Keep personal information private.
- Use secure authentication methods.
- Report suspicious activities.
- Keep dependencies updated.

Our Commitment

We are committed to improving the security and safety of Zezow Lesson AI.
